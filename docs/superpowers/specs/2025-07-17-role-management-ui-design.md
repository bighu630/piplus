# 角色管理 Tab UI 优化

日期: 2025-07-17

## 范围

只改前端 UI，不改后端 API、数据库、业务逻辑。

## 组件结构

```
SettingsPanel.tsx
  └─ RoleManager.tsx          (新增，替代内联 JSX)
       ├─ RoleCard.tsx         (每个角色分组卡片)
       ├─ VersionList.tsx      (展开后的版本列表)
       ├─ EditForm.tsx         (编辑模板的内联表单)
       └─ NewRoleForm.tsx      (新建角色/版本表单)
```

## 1. 列表展示

- 角色名称（name）为主显示，key 为副信息
- 内置角色显示蓝色 "内置" 标签，自定义角色显示绿色 "自定义" 标签
- 卡片右侧显示版本数量和最近编辑时间（相对时间格式）
- 使用与其他 Tab 一致的卡片容器样式

## 2. 版本管理

- 按 updated_at 降序排列，最新排最前
- 最新版本左侧蓝色竖线 + 蓝色 "最新" 标签高亮
- 内置版本（isBuiltin=true）操作按钮显示 "查看" + "复制新建"，不显示 "编辑"
- 自定义版本显示 "编辑" + "复制新建" + "删除"
- 每个版本显示相对编辑时间
- "新建版本" 改为内联表单而非 prompt() 弹窗

## 3. 编辑体验

- 编辑 textarea 增大到约 10-12 行，支持 resize:vertical
- 保持等宽字体 font-mono
- 显示字符计数和行数统计
- 描述输入框有清晰的 placeholder

## 4. 新建角色/版本

- 新建角色：Key(2) + 版本(1) 并排，名称、描述各占一行，basePrompt + 图标左右布局
- 新建版本：在版本列表底部内联展开，继承当前 basePrompt
- 必填字段标记红色星号
- 内联错误提示替代 alert()
- 图标选择器保持弹窗模式但优化尺寸

## 5. 整体风格

- 复用项目设置 Tab 的卡片/排版/按钮/暗色模式样式
- 不引入新颜色体系
- 每个元素维护 dark: 变体
